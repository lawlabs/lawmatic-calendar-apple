# Отображение типов дней

Приложение использует общую конфигурацию Kalends для основного календаря и
мини-календаря. Нужны изменения в обоих соседних репозиториях:
`lawmatic-calendar-apple` и `kalends-swiftui`.

Классификация хранится в памяти у `CalendarViewModel` и передаётся в
`KalendsDayConfiguration.dayInfoProvider`. `setDayInfo(_:for:)` нормализует дату
к началу дня; `nil` удаляет уточнение и возвращает субботне-воскресное правило.
События и синхронизация не меняются. Готовый производственный календарь страны
не включён.

## Проверки сборки на Mac

В репозитории библиотеки:

```bash
swift test
xcodebuild build -scheme Kalends -destination 'generic/platform=iOS Simulator'
```

В репозитории приложения:

```bash
xcodebuild test -scheme LawMaticCalendar -destination 'platform=macOS' CODE_SIGNING_ALLOWED=NO
xcodebuild build -scheme LawMaticCalendar-iOS -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO
```

В Windows выполнена проверка синтаксиса изменённых Swift-файлов. Компиляция,
XCTest и визуальные проверки требуют macOS/Xcode; они здесь не выполнялись.

## Проверка интерфейса

Запустить собранное приложение с аргументами:

```bash
open -n LawMaticCalendar.app --args -demo 1 -demoDayKinds 1 -date 2026-09-23 -mode week -colorScheme light
```

Те же аргументы поддерживаются в iOS Simulator через `xcrun simctl launch`.
Для тёмной темы заменить `light` на `dark`.

Это вымышленные статусы только для проверки оформления:

| Дата | Статус | Отметка |
| --- | --- | --- |
| 21 сентября | Праздник | П |
| 22 сентября | Перенесённый выходной | ↔ |
| 24 сентября | Сокращённый рабочий день | −1ч / * |
| 26 сентября | Перенесённый сокращённый рабочий день | Р −1ч / Р* |
| 27 сентября | Обычный выходной по умолчанию | Вых / В |

Проверить на Mac, iPhone и iPad в светлой и тёмной темах:

- В режиме дня, недели, месяца, года и мини-календаре видны соответствующие
  отметки; выбор даты и индикатор сегодняшнего дня остаются различимыми.
- Рабочая суббота 26 сентября не имеет фона нерабочего дня.
- Выключение подсветки выходных оставляет все семь столбцов и подсветку
  праздников; выключение подсветки праздников оставляет подсветку воскресенья.
- Выключение рабочих отметок скрывает «Р», «−1ч» и «*», сохраняя «↔».
- Скрытие субботы/воскресенья оставляет пять столбцов в неделе и месяце;
  заголовки, полоса событий на весь день и часовая сетка совпадают по ширине.
  Год и мини-календарь сохраняют все даты. После включения выходных события
  снова видны.
- Перетаскивание события в неделе попадает в показанный столбец, включая
  календарь с началом недели в четверг: с пятницы вправо — на понедельник.
- Подсказки дат и VoiceOver объясняют статус, даже когда подсветка выключена.

Обычный запуск без демо-флагов показывает только настоящие данные пользователя
и стандартные субботу/воскресенье, пока приложение не получит уточнения дат.
